
# Revision Scolaire

Application web privée de révision scolaire pour deux enfants.

## Objectifs

- Importer temporairement des photos de cours.
- Extraire et valider le texte avec un OCR.
- Générer des fiches de révision et des exercices.
- Suivre les tentatives et la progression.
- Limiter les coûts d'infrastructure et d'IA.

## Stack envisagée

- Python 3.11
- Streamlit
- FastAPI
- PostgreSQL
- Worker Python
- Docker Compose

## État du projet

Phase de préparation du socle technique.

Aucune donnée réelle de cours ni aucun secret ne doivent être versionnés dans ce dépôt.
